# سایت نمایش ربات‌های Nexbot

سایت تک‌صفحه‌ای (فارسی، راست‌به‌چپ) با تم مشکی و سبز برای معرفی ربات‌های تیم **Nexbot**:

- **ارماک (ARMAK)** — ربات مدیریت گروه روبیکا
- **هارویکس (Harwicks)** — ربات مدیریت گروه روبیکا

طراح سایت: artin Rashidi

---

## ساختار فایل‌ها

```
nexbot-site/
├── public/
│   └── index.html     ← خود سایت (HTML + CSS + JS، همه‌چیز داخل یک فایل)
├── server.js          ← سرور ساده‌ی Node.js برای نمایش سایت
├── data/              ← خودکار ساخته می‌شه؛ اطلاعات شمارنده‌ی کاربران (visitors.json)
├── package.json       ← برای هاست‌هایی که از npm start استفاده می‌کنن
└── README.md          ← همین راهنما
```

---

## اجرا روی کامپیوتر خودت

نیاز به **Node.js** (نسخه ۱۶ یا بالاتر) داری. هیچ پکیج اضافه‌ای لازم نیست.

```bash
node server.js
```

بعد توی مرورگر باز کن: http://localhost:3000

تغییر پورت:

```bash
PORT=8080 node server.js
```

## آنلاین کردن سایت

### روش ۱: هاست استاتیک (ساده‌ترین، رایگان)

چون سایت فقط یک فایل HTML هست، به سرور Node نیازی نداری. فقط محتوای پوشه‌ی `public/` (یعنی `index.html`) رو روی یکی از این سرویس‌ها آپلود کن:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Liara (بخش سایت استاتیک)

### روش ۲: هاست Node.js

اگه هاستت Node.js پشتیبانی می‌کنه (مثل Liara یا هاست‌های cPanel با Node):

1. کل این پوشه رو آپلود کن.
2. دستور شروع رو `npm start` (یا `node server.js`) بذار.
3. پورت رو از متغیر محیطی `PORT` می‌خونه، پس معمولاً نیاز به تنظیم دیگه‌ای نیست.

### وصل کردن دامنه‌ی .ir

1. دامنه رو از یکی از نمایندگی‌های ثبت دامنه ایران بخر.
2. توی پنل همون نمایندگی، رکوردهای DNS (A یا CNAME) رو طبق آدرسی که هاست بهت داده تنظیم کن.
3. بعد از چند ساعت (حداکثر ۲۴ ساعت) دامنه به سایت وصل می‌شه.

### دیده شدن در گوگل

بعد از آنلاین شدن، با حساب گوگل خودت وارد [Google Search Console](https://search.google.com/search-console) شو، دامنه رو ثبت کن و درخواست ایندکس بده.

## شخصی‌سازی سریع

همه‌ی تغییرات داخل `public/index.html` انجام می‌شن.

| چیزی که می‌خوای عوض کنی | چی رو جستجو کن |
|---|---|
| لینک ربات ارماک | `rubika.ir/armakbot` |
| لینک ربات هارویکس | `rubika.ir/HarWicksbot` |
| لینک کانال خبری Nexbot | `rubika.ir/Join_NEXBOT` |
| لینک پشتیبانی | `rubika.ir/artin_13_Rashidi` |
| وضعیت ربات‌ها (روشن / در حال بروزرسانی) | `status-badge` |
| تاریخ تایمر معکوس نسخه‌ی جدید | `countdownTarget` |
| متن تایپ‌رایتر زیر لوگو | `taglineStr` |
| رنگ‌های سایت | بخش `:root` و کلاس‌های رنگی بالای فایل |
| متن فوتر (طراح سایت) | `<footer` |

### تغییر وضعیت یک ربات

نشان وضعیت بالای سمت راست هر کارت:

- سبز («روشن»):
  `<span class="status-badge"><span class="status-dot"></span>وضعیت: روشن</span>`
- طوسی («در حال بروزرسانی»):
  `<span class="status-badge status-grey"><span class="status-dot"></span>وضعیت: در حال بروزرسانی</span>`

## امکانات سایت

- پس‌زمینه‌ی مشکی با درخشش سبز و گرید ظریف
- لوگوی Nexbot با متن تایپ‌رایتر که هر ۱۵ ثانیه دوباره تایپ می‌شه
- بخش «خدمات ما» به شکل کروسل (اسلاید با فلش چپ/راست) که با کلیک روی هر اسلاید صفحه‌ی مربوطه باز می‌شه
- کارت ربات‌ها با نشان وضعیت
- منوی سه‌خطی: نسخه جدید از ربات‌ها (با تایمر معکوس)، کانال خبر از تیم Nexbot، معرفی تیم ما، پشتیبانی
- منوی «تعداد کاربران سایت»: هر بازدیدکننده‌ی جدید (با شناسه‌ی تصادفی ذخیره‌شده در مرورگرش) یکی به شمارنده اضافه می‌کنه و لیست کاربران (شماره، زمان اولین ورود، تعداد بازدید) نمایش داده می‌شه. هیچ IP یا اطلاعات شخصی ذخیره نمی‌شه.
- ریسپانسیو و مناسب موبایل

## نکات فنی

- **شمارنده‌ی کاربران فقط با `server.js` کار می‌کنه** (API: `POST /api/visit` و `GET /api/stats`). روی هاست استاتیک (GitHub Pages و ...) عدد نمایش داده نمی‌شه. روی هاست Node حتماً پوشه‌ی `data/` ماندگار (persistent) باشه تا با ری‌استارت، آمار پاک نشه.
- یک نفر با پاک کردن اطلاعات مرورگر یا استفاده از مرورگر دیگه، دوباره یک کاربر جدید حساب می‌شه.
- `server.js` فقط از پوشه‌ی `public/` فایل سرو می‌کنه و جلوی دسترسی به بقیه‌ی فایل‌های سرور رو می‌گیره.
- فونت‌ها (Vazirmatn و Orbitron) از Google Fonts لود می‌شن؛ بدون اینترنت از فونت پیش‌فرض سیستم استفاده می‌شه.
- تصاویر لوگوها داخل خود `index.html` به‌صورت base64 جاسازی شدن، پس فایل جداگانه‌ای برای عکس لازم نیست.
